## 🪝 Hook Masterclass — 3 Detik Pertama Menentukan Segalanya

```
FAKTA: 73% penonton TikTok dan 67% Reels memutuskan untuk lanjut atau tidak
dalam 3 DETIK PERTAMA

Artinya: Hook = 70% keberhasilan video Anda
```

### 10 Hook Formula Terkuat

**1. THE SHOCKING FACT**
```
"[Fakta mengejutkan yang membantah kepercayaan umum]"
Contoh: "90% orang Indonesia tidak tahu kalau ini ilegal"
         "Kamu sudah rugi Rp X tanpa sadar"
```

**2. THE DIRECT CHALLENGE**
```
"Kalau kamu [target audience], tonton ini sampai selesai"
"Jangan scroll kalau kamu [pain point]"
Contoh: "Kalau kamu masih susah dapat klien, ini yang salah"
```

**3. THE CONTROVERSIAL TAKE**
```
"[Kepercayaan populer] itu bohong. Ini faktanya:"
"Semua orang bilang [X] tapi sebenarnya [Y]"
Contoh: "Posting setiap hari itu bukan kunci sukses sosmed"
```

**4. THE RESULT FIRST**
```
Tunjukkan hasil akhir dulu, LALU jelaskan prosesnya
"Ini yang terjadi setelah saya [action] selama 30 hari"
Video dimulai dengan HASIL, bukan proses
```

**5. THE TRANSFORMATION PROMISE**
```
"Dalam [timeframe pendek], kamu akan [perubahan konkret]"
Contoh: "Dalam 10 menit, kamu akan bisa [skill baru]"
```

**6. THE RELATABLE SITUATION**
```
"Kalau kamu pernah [situasi relatable], ini untuk kamu"
"Pernah ngerasa [frustrasi umum]? Ini solusinya."
```

**7. THE CURIOSITY GAP**
```
Setup situasi tanpa kasih jawaban: "Saya hampir [negatif] karena ini..."
Buat penonton HARUS tonton sampai akhir untuk dapat closure
```

**8. THE AUTHORITY CLAIM**
```
"Setelah [X tahun/pengalaman spesifik], saya baru sadar:"
"Saya sudah analisis [angka besar] dan hasilnya:"
```

**9. THE PATTERN INTERRUPT**
```
Mulai dengan sesuatu yang TIDAK TERDUGA untuk format tersebut
Pertanyaan retoris yang tidak biasa, visual yang surprising
```

**10. THE STAKES**
```
"Kalau kamu tidak tahu ini, kamu akan [konsekuensi negatif]"
"Ini satu hal yang bisa [hancurkan/selamatkan] bisnis kamu"
```

## 📺 YouTube Long-Form

### Blueprint Script 10-20 Menit

```
STRUKTUR WAKTU (video 15 menit):

[0:00 - 0:30] HOOK (30 detik)
→ Hook statement atau visual yang memaksa tonton
→ Preview: "Di video ini kamu akan belajar [X, Y, Z]"
→ Pattern interrupt: mulai di tengah action/situasi

[0:30 - 2:00] INTRO (90 detik)
→ Siapa kamu dan mengapa KAMU yang layak bicara soal ini
→ Preview lebih detail dari konten
→ "Tonton sampai menit ke-X karena ada [bonus/surprise/paling penting]"

[2:00 - 12:00] MAIN CONTENT (10 menit)
→ 3-5 poin utama, masing-masing 2-3 menit
→ Setiap poin: state → explain → example → implication
→ Re-engagement hook setiap 3-4 menit ("Dan ini yang lebih penting lagi...")

[12:00 - 14:00] SYNTHESIS (2 menit)
→ Ringkasan poin utama
→ "Jadi kalau kamu harus ingat satu hal dari video ini..."
→ Hubungkan semua poin ke takeaway utama

[14:00 - 15:00] OUTRO & CTA (1 menit)
→ Strong CTA: subscribe, like, komentar
→ Tease video berikutnya
→ Link ke resource tambahan
```

## 🎭 Instagram Reels

### Formula 30-Detik Terbaik

```
[0-3 detik]   VISUAL + AUDIO HOOK
              Sesuatu yang langsung menarik tanpa audio pun

[3-10 detik]  SETUP & TENSION
              Bangun konteks, munculkan masalah atau rasa ingin tahu

[10-25 detik] PAYOFF / VALUE
              Deliver apa yang dijanjikan hook
              Specific, actionable, fast-paced

[25-30 detik] MICRO-CTA
              "Save ini", "Coba di kolom komentar", "Tag teman"
```

### 5 Format Reels yang Paling Viral

**FORMAT 1: Tutorial Cepat**
```
Hook: Tunjukkan hasil akhir
Step: [Langkah 1] → [Langkah 2] → [Langkah 3]
CTA: "Simpan untuk dicoba nanti"
```

**FORMAT 2: Before vs After**
```
Hook: "Dulu vs Sekarang" atau teks besar di screen
Split: Keadaan buruk | Keadaan baik
CTA: "Ini yang saya lakukan berbeda"
```

**FORMAT 3: Myth Busting**
```
Hook: "Kamu salah soal [X]"
Content: Mitos → Fakta (dengan bukti)
CTA: "Share ke yang masih percaya mitos ini"
```

**FORMAT 4: Personal Story Arc**
```
Hook: Titik terendah atau momen mengejutkan
Middle: Perjalanan dan proses
End: Transformasi dan lesson
CTA: Tanya pengalaman serupa di komentar
```

**FORMAT 5: Rapid Fire Value**
```
Hook: "[Angka] hal yang [audience] harus tahu"
Content: Satu bullet point per 2-3 detik, cepat
End: "Yang paling penting adalah yang terakhir"
CTA: "Save untuk referensi"
```

## 🤖 AI Script Generator — Prompt Templates

### Generate Script YouTube Lengkap

```
Kamu adalah script writer profesional untuk channel YouTube [NICHE].

TOPIK VIDEO: [judul video]
TARGET AUDIENCE: [deskripsi penonton]
DURASI TARGET: [X menit]
TONE: [educational/entertaining/inspirational]
GOAL: [brand awareness/subscribers/traffic ke website]

Buat script YouTube lengkap dengan struktur:

1. HOOK (30 detik): [pilih 1 hook formula — shocking fact/controversy/result first]
2. INTRO (60-90 detik): perkenalan + preview konten + pattern interrupt
3. MAIN CONTENT ([X] segmen): 
   - Segmen 1: [poin 1]
   - Segmen 2: [poin 2]
   - Segmen 3: [poin 3]
   (setiap segmen: state → elaborate → example → implication)
4. RE-ENGAGEMENT HOOKS: di menit ke-3, 7, 11 (jika video panjang)
5. SYNTHESIS: ringkasan dan key takeaway
6. CTA OUTRO: subscribe, like, komentar prompt, next video tease

Format output: Script lengkap dengan [TIME STAMP] dan [VISUAL DIRECTION] di setiap segmen.
Tambahkan [B-ROLL SUGGESTIONS] untuk editor.
Sertakan thumbnail title suggestion (max 6 kata).
```
